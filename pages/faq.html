  • We set the “rel” attribute, which defines the relationship between the page and the linked URL, to “noopener noreferrer” to prevent phishing known as “tabnabbing.”
    Tabnabbing, or reverse tabnabbing, is a way to exploit the browser that uses its default behavior with target="_blank" to gain partial access to the page through the "window.object" API.

  • Libre Busca was built using HTML 5 and CSS 3. It was also built with PHP 7 and SQL for database functionality, and has a little JavaScript that changes the tab title to “New tab” when the user goes to another tab, so that no one knows what that tab is about, helping a little with user privacy, and to make the navbar with links responsive.

  • We used local storage to save the website mode preference, i.e., dark mode or light mode, so that users would not have to choose the mode every time they accessed the website. Learn more about "local storage" here: https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage. But we switched to “prefers-color-scheme,” so the site will automatically change themes depending on the user's browser/PC preference. But we may add Local Storage again so that users can choose the theme manually as well.
